# Maze Runner Game

A simple but engaging maze runner game built with HTML5 Canvas and JavaScript. The game generates a random maze each time you play, ensuring there's always a valid path from start to finish.

## Features

- Random maze generation using recursive backtracking algorithm
- Guaranteed solvable mazes
- Player movement with arrow keys
- Timer to track completion time
- Visual feedback (player position, walls, start/end points)
- Restart functionality

## How to Play

1. Use the arrow keys to move the green player circle
2. Navigate from the green square (start) to the red square (end)
3. Avoid the black walls
4. Try to complete the maze in the shortest time possible
5. Click the "Restart Game" button to generate a new maze

## Setup

1. Clone this repository
2. Open `index.html` in a web browser
3. Start playing!

## Files

- `index.html` - Main game page
- `styles.css` - Game styling
- `game.js` - Game logic and maze generation

## Development

To run the game locally with auto-reload:

1. Install Python 3
2. Run `python3 -m http.server 8000`
3. Open `http://localhost:8000` in your browser
